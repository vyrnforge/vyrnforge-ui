# @vyrnforge/icons

Optional official VyrnForge SVG glyph catalog.

The shared `IconDefinition` contract and canonical Icon styling live in `@vyrnforge/web`. This package owns authored glyph artwork and exposes granular entrypoints such as `@vyrnforge/icons/bookmark` so applications can consume only the icons they need.

Framework and Elements packages do not depend on this catalog. Consumers may use VyrnForge glyphs or provide their own compatible icon definitions.
