Layer 1 is the elemental, non-interactive foundation above L0. The canonical inventory distinguishes public primitives, private visual recipes, native-first HTML, and candidates that remain deliberately deferred.

Core L1

The established Core L1 set is Text, Icon, Surface, Separator, and VisuallyHidden. Their component contracts remain authoritative.

Promoted elemental primitives

These non-interactive candidates are now part of the Layer 1 Web contract:

  • Code — use native code or pre semantics with data-vf-code / data-vf-code-block.
  • Kbd — use native kbd with data-vf-kbd.
  • Mark — use native mark with data-vf-mark.
  • Image — use native img with data-vf-image; ordinary HTML alternative-text rules remain authoritative.
  • Skeleton — use data-vf-skeleton on a decorative placeholder. The placeholder is not the accessible loading message and should be aria-hidden="true".
  • ColorSwatch — use data-vf-color-swatch and set --vf-color-swatch. If color conveys meaning, provide equivalent text or an authored accessible name.

All six are CSS/native-first. They do not introduce keyboard behavior, Core runtime, or mandatory framework wrappers.

Deferred candidates

StatusIndicator is deferred until higher-layer consumers prove a stable semantic status vocabulary and non-color communication contract. AvatarFallback is deferred until Avatar composition, image-failure policy, fallback ownership, and naming behavior are defined. These are explicit architecture decisions rather than missing implementations.

Internal L1 recipes

Checkmark, Radiomark, and SelectionIndicator are private Web-owned visual recipes for later selectable controls. They are not public exports or public data hooks. Semantic checked/selected state always belongs to the owning native or ARIA control.

Native-first primitives

VyrnForge keeps document semantics native. Add data-vf-prose to an authored container to opt into token-driven presentation for native semantic content. No Heading, Paragraph, Quote, Blockquote, Figure, or List wrapper is required.

Supported native elements include blockquote, q, h1–h6, p, figure, figcaption, ul, ol, li, strong, em, small, sub, sup, abbr, address, cite, and time. Native code, kbd, and mark also retain their semantics inside prose.

Consumption

The aggregate @vyrnforge/web/styles.css includes Layer 1 elemental styling. Consumers that want only this tranche can load @vyrnforge/web/styles/elemental-primitives.css. The stylesheet is low-specificity, token-driven, SSR-safe, logical-property based, reduced-motion aware, and compatible with forced-colors environments.

Accessibility

Layer 1 does not recreate browser semantics or keyboard interaction. Native elements remain the source of semantics. Skeleton is decorative, Image keeps ordinary alt requirements, and ColorSwatch must never make color the only carrier of meaning.
