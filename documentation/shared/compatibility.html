Component availability

Framework support is component-specific. Use each component page and framework guide to confirm that the surface you need is available; the existence of a framework package does not imply that every VyrnForge component is available in that environment.

Browser support

This is the next preview channel. A final release-qualified browser support range is not yet published. Component pages identify browser-dependent behavior that requires special consideration, including modal APIs, focus behavior, hydration, or custom-element upgrade.

Server rendering

SSR and hydration support are documented per component for React, Angular, and Vue. Elements uses browser registration and upgrade rather than framework hydration. Native Web does not require a framework hydration step.
