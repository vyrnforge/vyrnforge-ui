VyrnForge is being rebuilt as a native-web-first, multi-framework UI foundation. This documentation channel describes the implementation currently on the rebuild branch and does not imply that unfinished framework surfaces are released.

Current channel

The next channel tracks unreleased rebuild work. Stable versioned documentation will be introduced by the release workflow when a supported package release exists.

Foundation first

VyrnForge standardizes semantic contracts, accessibility, state and behavior, design tokens, canonical CSS, package boundaries, testing, documentation, and framework integration before growing the component catalog.

Before using packages

The package skeleton is intentionally private during bootstrap. Framework pages clearly show implementation status; do not treat a package scaffold as shipped component support.
