VyrnForge styling is available through public CSS entrypoints, design tokens, and stable component hooks. Use those documented surfaces to adapt the library to your application without depending on undocumented selectors.

Load styles

import '@vyrnforge/web/styles.css';

You can also load a documented component stylesheet such as @vyrnforge/web/styles/button.css when your application only needs that component's styles.

Cascade layers

@layer vyrnforge.reset, vyrnforge.tokens, vyrnforge.themes, vyrnforge.foundation, vyrnforge.components;

The reset is optional. Tokens, themes, foundations, and component styles are ordered so application styles can customize VyrnForge predictably.

Customization hierarchy

Prefer public semantic tokens first, then documented component tokens, then stable styling hooks, then ordinary application CSS. Public VyrnForge custom properties use the --vf-* prefix.

Framework usage

React, Angular, Vue, Elements, and Native Web use the same public styling entrypoints. Framework guides show where to load styles and component pages list any additional supported hooks.
