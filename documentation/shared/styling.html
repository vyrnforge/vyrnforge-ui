All framework ports consume one canonical web styling system from @vyrnforge/web. Framework guides may explain where styles are loaded, but they do not define separate styling architectures.

Cascade contract

@layer vyrnforge.reset, vyrnforge.tokens, vyrnforge.themes, vyrnforge.foundation, vyrnforge.components;

The reset is optional. Tokens, themes, foundations, and component styles remain ordered and intentionally overridable.

Customization hierarchy

Prefer semantic tokens, then public component tokens, then stable styling hooks, then ordinary application CSS. Public custom properties use --vf-*; --_vf-* is private implementation state.

Framework reuse

This page is the shared styling explanation for React, Angular, Vue, Elements, and Native Web. Framework documentation references this source instead of maintaining copied styling rules.
