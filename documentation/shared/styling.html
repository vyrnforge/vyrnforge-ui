VyrnForge styling is available through public CSS entrypoints, generated design tokens, and stable component hooks. Use those documented surfaces to adapt the library to your application without depending on undocumented selectors.

Load styles

import '@vyrnforge/web/styles.css';

The aggregate stylesheet includes runtime tokens, built-in themes, shared foundation styling, and component CSS. It intentionally does not include the optional global reset.

import '@vyrnforge/web/styles/reset.css';

Load the reset separately only when your application wants VyrnForge's conservative normalization. You can also load @vyrnforge/web/styles/foundation.css, @vyrnforge/web/styles/tokens.css, or a documented component stylesheet such as @vyrnforge/web/styles/button.css when you need a narrower surface.

Cascade layers

@layer vyrnforge.reset, vyrnforge.tokens, vyrnforge.themes, vyrnforge.foundation, vyrnforge.components;

The reset is optional. Tokens, themes, foundations, and component styles are ordered so application styles can customize VyrnForge predictably.

Design token pipeline

Reference design decisions are repository-internal authoring inputs. VyrnForge generates the public runtime token and theme contract as CSS custom properties in @vyrnforge/web. Runtime themes use the same semantic token names rather than replacing component CSS or requiring a JavaScript theme runtime.

Shared foundation helpers

The foundation stylesheet owns cross-component styling responsibilities rather than framework-specific copies. It currently provides the documented data-vf-visually-hidden accessibility hook and shared reduced-motion plumbing.

Customization hierarchy

Prefer public semantic tokens first, then documented component tokens, then stable styling hooks, then ordinary application CSS. Public VyrnForge custom properties use the --vf-* prefix. Private implementation variables use the --_vf-* convention and are not compatibility commitments.

Framework usage

React, Angular, Vue, Elements, and Native Web use the same public styling entrypoints. Framework guides show where to load styles and component pages list any additional supported hooks.
