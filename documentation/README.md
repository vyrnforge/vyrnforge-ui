# Public documentation sources

Repository documentation is a consumer-facing projection of canonical VyrnForge contracts. It must not become an independent source of semantic truth.

Content is organized by responsibility:

- `shared/` — framework-neutral foundations and component explanations authored once.
- `frameworks/` — idiomatic framework adaptation content only.
- `reference/` — generated or implementation-derived public reference material when reliable.

Executable examples should be shared with validation wherever practical.
