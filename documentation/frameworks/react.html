Status: React integration is available for the components documented in this channel.

Install the React package alongside the supported React runtime, load VyrnForge styles, and import components from their documented subpaths.

Available component entrypoints

  • @vyrnforge/react/button
  • @vyrnforge/react/dialog
  • @vyrnforge/react/icon
  • @vyrnforge/react/tabs
  • @vyrnforge/react/text

Use the corresponding component page for props, accessibility behavior, examples, and styling guidance.

Example

import '@vyrnforge/web/styles.css';
import { Button } from '@vyrnforge/react/button';

export function SaveButton() {
  return <Button variant="primary">Save</Button>;
}

Native props and events

VyrnForge React components preserve the native attributes and event patterns documented for each component. Prefer the normal React event surface unless a component page documents an additional VyrnForge callback.

SSR and hydration

Server-rendering support is documented per component. Follow the component page when behavior depends on browser APIs, focus, modal activation, or client-side upgrade.
