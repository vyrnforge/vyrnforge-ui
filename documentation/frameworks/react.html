Component entrypoints

The component navigation and route availability in this React view are derived from the Product Graph. Treat the selected component page as the authority for its public entrypoint, props, callbacks, accessibility execution, executable examples, and SSR/hydration notes rather than relying on a separately maintained component list.

Native props and events

VyrnForge React components preserve the native attributes and event patterns documented for each component. Prefer the normal React event surface unless a component page documents an additional VyrnForge callback.

SSR and hydration

Server-rendering support is documented per component. Follow the component adaptation when behavior depends on browser APIs, focus, modal activation, or client-side hydration.
