Status: Button baseline implemented at React 19.3.x.

Shared Button semantics, accessibility, forms, state, and styling are documented once on the Button page.

Button

import { Button } from '@vyrnforge/react/button';

<Button variant="primary" size="md" loading={saving} onClick={save}>Save</Button>

The component forwards native button props and its ref. onClick remains the native activation callback; no second VyrnForge activation event is added.

SSR and hydration

Server output is a native button with stable VyrnForge state hooks. Hydration restores React event wiring without requiring a Button controller or browser-only semantic initialization.
