Status: Elements integration is available for the component surfaces published in this framework view.

Use the Elements package when you want documented VyrnForge custom-element APIs without a framework runtime. Custom elements are registered explicitly so importing a module does not register elements as a side effect.

Component entrypoints

The component navigation and route availability in this Elements view are derived from the Product Graph. Treat each component page as the authority for its public entrypoint, registration function, attributes, properties, custom events, authored markup, and executable example. Unsupported routes remain explicit rather than substituting another framework.

Explicit registration

import { defineTabsElement } from '@vyrnforge/elements/tabs';

defineTabsElement();

Call the documented registration function before using the corresponding custom element.

Attributes, properties, and events

Use only the attributes, properties, and custom events listed by the selected component adaptation. Rich JavaScript values that cannot be represented safely as attributes are exposed through documented properties.

Browser rendering

Elements components become interactive after registration and browser upgrade. Component adaptations document any authored markup that must be present before upgrade and any behavior that differs from server-rendered framework components.
