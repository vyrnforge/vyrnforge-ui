Status: Button deliberately unavailable in Elements.

The Elements package remains rebuild scaffolding. Button was evaluated for the first component slice, but an autonomous custom element would not be a native button before upgrade and would require reimplementing native button/form behavior; customized built-in buttons are not a sufficiently portable baseline. VyrnForge therefore defers Elements Button rather than shipping weaker semantics.

Shared contract

The semantic target remains the shared Button contract. A future Elements implementation must preserve that native-first contract rather than redefining it.
