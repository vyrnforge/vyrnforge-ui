Status: Elements integration is available for Icon and Tabs in this channel.

Use the Elements package when you want the documented VyrnForge custom-element APIs without a framework runtime. Custom elements are registered explicitly so importing a module does not register elements as a side effect.

Available component entrypoints

  • @vyrnforge/elements/icon
  • @vyrnforge/elements/tabs

Button, Dialog, and Text do not currently expose Elements-specific component entrypoints. Their component pages show the supported alternatives where applicable.

Explicit registration

import { defineTabsElement } from '@vyrnforge/elements/tabs';

defineTabsElement();

Call the documented registration function before using the corresponding custom element.

Attributes, properties, and events

Use the attributes, properties, and custom events listed on each component page. Rich JavaScript values that cannot be represented safely as attributes are exposed through documented properties.

Browser rendering

Elements components become interactive after registration and browser upgrade. Component pages document any authored markup that must be present before upgrade and any behavior that differs from server-rendered framework components.
