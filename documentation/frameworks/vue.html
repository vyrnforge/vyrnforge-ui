Status: Button baseline implemented at Vue 3.5.x.

Shared Button semantics, accessibility, forms, state, and styling are documented once on the Button page.

Button

import { Button } from '@vyrnforge/vue/button';

<Button variant="primary" size="md" :loading="saving" @click="save">Save</Button>

The component renders a native button, forwards fallthrough native attributes, and uses the default slot for ordinary content.

SSR and hydration

Vue SSR output is native-complete. Hydration restores Vue event wiring without changing the Button semantic state.
