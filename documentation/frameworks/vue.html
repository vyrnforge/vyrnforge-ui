Status: Vue integration is available for the components documented in this channel.

Install the Vue package alongside the supported Vue runtime, load VyrnForge styles, and import components from their documented subpaths.

Available component entrypoints

  • @vyrnforge/vue/button
  • @vyrnforge/vue/dialog
  • @vyrnforge/vue/icon
  • @vyrnforge/vue/tabs
  • @vyrnforge/vue/text

Use the corresponding component page for props, emitted events, accessibility behavior, examples, and styling guidance.

Example

<script setup>
import { Button } from '@vyrnforge/vue/button';
</script>

<template>
  <Button variant="primary">Save</Button>
</template>

Attributes and events

VyrnForge Vue components preserve the native attributes and Vue event patterns documented for each component. Use additional emitted events only where the component page documents them.

SSR and hydration

Server-rendering support is documented per component. Follow the component page when behavior depends on browser APIs, focus, modal activation, or hydration.
