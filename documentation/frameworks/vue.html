Component entrypoints

The component navigation and route availability in this Vue view are derived from the Product Graph. Treat the selected component page as the authority for its public entrypoint, props, emitted events, accessibility execution, executable examples, and SSR/hydration notes rather than relying on a separately maintained component list.

Attributes and events

VyrnForge Vue components preserve the native attributes and Vue event patterns documented for each component. Use additional emitted events only where the selected component adaptation documents them.

SSR and hydration

Server-rendering support is documented per component. Follow the component adaptation when behavior depends on browser APIs, focus, modal activation, or hydration.
