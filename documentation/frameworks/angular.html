Status: Button baseline implemented at Angular 22.x.

Shared Button semantics, accessibility, forms, state, and styling are documented once on the Button page.

Button

import { VfButtonDirective } from '@vyrnforge/angular/button';

@Component({ imports: [VfButtonDirective] })
class Example {}

<button vfButton variant="primary" size="md" [loading]="saving" (click)="save()">Save</button>

The standalone directive decorates an actual native <button>; native Angular event syntax and form attributes remain available.

SSR and hydration

Server rendering preserves the native button and directive-owned stable attributes. Hydration restores Angular event wiring without replacing the control.
