Status: Angular integration is available for the components documented in this channel.

Install the Angular package alongside the supported Angular runtime, load VyrnForge styles, and import standalone directives or components from their documented subpaths.

Available component entrypoints

  • @vyrnforge/angular/button
  • @vyrnforge/angular/dialog
  • @vyrnforge/angular/icon
  • @vyrnforge/angular/tabs
  • @vyrnforge/angular/text

Use the corresponding component page for inputs, outputs, accessibility behavior, examples, and styling guidance.

Example

import { VfButtonDirective } from '@vyrnforge/angular/button';

@Component({
  imports: [VfButtonDirective],
  template: '<button vfButton variant="primary">Save</button>'
})
export class Example {}

Native elements and events

Directive-based VyrnForge APIs keep the authored native element and Angular's normal event and attribute syntax. Use additional outputs only when a component page documents them.

SSR and hydration

Server-rendering support is documented per component. Follow the component page when behavior depends on browser APIs, focus, modal activation, or client-side hydration.
