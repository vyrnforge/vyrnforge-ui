Status: Angular integration is available for the component surfaces published in this framework view.

Install the Angular package alongside the supported Angular runtime, load VyrnForge styles, and import standalone directives or components from their documented subpaths.

Component entrypoints

The component navigation and route availability in this Angular view are derived from the Product Graph. Treat the selected component page as the authority for its public entrypoint, inputs, outputs, accessibility execution, executable examples, and SSR/hydration notes rather than relying on a separately maintained component list.

Native elements and events

Directive-based VyrnForge APIs keep the authored native element and Angular's normal event and attribute syntax. Use additional outputs only when the selected component adaptation documents them.

SSR and hydration

Server-rendering support is documented per component. Follow the component adaptation when behavior depends on browser APIs, focus, modal activation, or client-side hydration.
