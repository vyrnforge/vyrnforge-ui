Status: Native Web styling and documented browser-facing APIs are available for the component surfaces published in this framework view.

Use Native Web when your application authors native HTML directly and wants VyrnForge styling and supported browser-facing contracts without a framework component layer.

Component coverage

The component navigation and route availability in this Native Web view are derived from the Product Graph. Each selected component page is the authority for its stylesheet entrypoint, semantic markup, public data hooks, required browser behavior, and executable example. A stylesheet surface does not imply that the browser supplies a compound component's behavior automatically.

Load styles

import '@vyrnforge/web/styles.css';

Component adaptations also identify focused stylesheet entrypoints such as @vyrnforge/web/styles/button.css.

Example

<button
  data-vf-button
  data-vf-variant="primary"
  data-vf-size="md"
  type="button"
>Save</button>

Native semantics and behavior

Author the correct native HTML element first, then apply the public VyrnForge hooks documented for that component. Native controls keep browser semantics; compound patterns such as Tabs still require the behavior contract documented by their component adaptation and executable example.
