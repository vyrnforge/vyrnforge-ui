Status: Native Web styling and documented data-hook APIs are available in this channel.

Use Native Web when your application authors native HTML directly and wants VyrnForge styling and supported browser-facing APIs without a framework component layer.

Load styles

import '@vyrnforge/web/styles.css';

Component pages also list focused stylesheet entrypoints such as @vyrnforge/web/styles/button.css.

Example

<button
  data-vf-button
  data-vf-variant="primary"
  data-vf-size="md"
  type="button"
>Save</button>

Native semantics

Author the correct native HTML element first, then apply the public VyrnForge hooks documented for that component. Native form behavior, keyboard activation, and focus semantics remain available unless a component page explicitly documents additional behavior.

JavaScript APIs

Some components expose public browser-facing TypeScript or JavaScript APIs through @vyrnforge/web subpaths. Import only the entrypoints documented by the component you are using.
