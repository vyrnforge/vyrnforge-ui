Status: Button baseline implemented.

Native Web uses the same semantic Button contract and canonical CSS without a JavaScript component runtime. See the shared Button documentation.

Button

import '@vyrnforge/web/styles/button.css';

<button data-vf-button data-vf-variant="primary" data-vf-size="md" type="button">Save</button>

Add data-vf-loading and aria-busy="true" together for loading state. Native disabled, form behavior, keyboard activation, and focus remain browser-owned.
