Menubar organizes persistent top-level command menus with horizontal keyboard navigation.

Overview

Use Menubar for a small persistent set of command-menu triggers.

Installation and imports

Import from /menubar and load the Web stylesheet.

Quick start

Anatomy

Root, Menu, Trigger, Content, and Item.

Interaction

Left and Right arrows move among top-level triggers; each trigger opens a normal Menu.

Accessibility

The root uses menubar semantics and its commands retain native button activation.

Testing guidance

Test horizontal navigation, nested menu behavior, SSR, and axe.
