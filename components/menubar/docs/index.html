Menubar organizes persistent top-level command menus with horizontal keyboard navigation.

Overview

Use Menubar for a small persistent set of command-menu triggers.

Installation and imports

Import from the framework-specific /menubar subpath and load @vyrnforge/web/styles/menubar.css.

Quick start

Anatomy

Root, Menu, Trigger, Content, and Item compose persistent top-level commands from the shared Menu contract.

State

Each child menu owns its open state while the menubar owns only peer trigger navigation.

Behavior

Horizontal navigation moves among top-level triggers; opened menus retain normal menu dismissal and selection behavior.

Interaction

Left and Right arrows move among top-level triggers while each trigger preserves native activation.

Accessibility

The root uses menubar semantics and child commands retain menu/menuitem semantics and accessible names.

Forms

Menubar is not form-associated and command triggers use non-submitting button behavior unless deliberately composed otherwise.

Styling

Canonical CSS is Web-owned, token-driven, and composes with Menu styling.

Framework API

All framework ports expose the same persistent command structure idiomatically without sharing a renderer runtime.

CSR and SSR

Imports are server safe; keyboard and popup behavior starts only after browser rendering.

Do / Don't

Do use for compact persistent application commands. Don't embed routing, permissions, or domain command dispatch inside VyrnForge.

Testing guidance

Test horizontal navigation, nested menu behavior, dismissal, focus, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling Menubar ports over the shared Menu concept.
