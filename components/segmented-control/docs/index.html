SegmentedControl presents mutually exclusive peer choices with radio-group semantics.

Overview

Use SegmentedControl for a small visible set of mutually exclusive options.

Installation and imports

Import from the framework-specific /segmented-control subpath and load @vyrnforge/web/styles/segmented-control.css.

Quick start

Anatomy

Root and Item form the exclusive choice group.

State

Exactly one authored value is selected when the consumer requires a selection; value ownership is framework-idiomatic.

Behavior

Activating an enabled item selects it and clears peer selection.

Interaction

Keyboard focus and activation follow radio-group expectations while preserving clear visible peer choices.

Accessibility

The root is a radiogroup and items expose radio/aria-checked state with an authored accessible name.

Forms

Consumers own name, required state, serialization, and validation policy.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same exclusive selection concept without framework-specific leakage into shared contracts.

CSR and SSR

Imports are server safe and selected state renders deterministically.

Do / Don't

Do use for a few peer choices. Don't use it for arbitrary application tabs or navigation where Tabs or links provide the correct semantics.

Testing guidance

Test exclusive selection, keyboard focus, disabled state, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling SegmentedControl ports.
