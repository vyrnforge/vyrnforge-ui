NumberInput is native numeric entry using input[type=number].

Overview

Use NumberInput for one numeric value where browser spin, constraint validation, and form behavior are appropriate.

Installation and imports

Load @vyrnforge/web/styles/number-input.css. React, Angular, and Vue use their /number-input entrypoints; Native Web uses data-vf-number-input.

Quick start

Accessibility

Provide an accessible label and use native min, max, step, disabled, readonly, and validation semantics.

Styling

Canonical numeric-input styling is owned by the Web package and uses shared tokens while retaining the native editable control and browser-provided numeric affordances.

Framework API

React and Vue expose NumberInput; Angular decorates input[vfNumberInput]. Value, min, max, step, required, disabled, and readonly behavior remain native attributes and properties.

Compatibility

Spinner presentation and invalid-value handling can vary by browser. Consumers should rely on the standard numeric input value and constraint-validation APIs rather than visual spinner details.

Layer boundary

A compound NumberField with separate stepper buttons coordinates multiple controls and belongs above Layer 2.
