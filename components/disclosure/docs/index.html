Disclosure progressively reveals authored content while preserving native button semantics and explicit relationships.

Overview

Use Disclosure for one independently expandable region.

Installation and imports

Import from each framework's /disclosure subpath and load @vyrnforge/web/styles/disclosure.css.

Quick start

Anatomy

Root, Trigger, and Panel.

Variants and sizes

No semantic variants or sizes.

State

Supports controlled and uncontrolled open state plus disabled state.

Behavior

The trigger toggles one panel and maintains aria-expanded and aria-controls.

Interaction

Uses native button keyboard activation.

Accessibility

Trigger remains a native button and the panel is hidden when collapsed.

Forms

The trigger uses type=button and does not submit forms.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose idiomatic Root, Trigger, and Panel composition.

CSR and SSR

Imports are server safe; browser behavior starts after rendering.

Examples

The basic example demonstrates one disclosure.

Do / Don't

Do use for progressive disclosure. Don't use as a generic application state container.

Testing guidance

Test activation, relationships, disabled state, focus, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared contract.
