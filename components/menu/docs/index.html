Menu presents a transient set of commands with menu semantics, directional keyboard navigation, dismissal, and focus restoration.

Overview

Use Menu for contextual commands opened from a trigger.

Installation and imports

Import from each framework's /menu subpath and load @vyrnforge/web/styles/menu.css.

Quick start

Anatomy

Root, Trigger, Content, Item, and Separator.

State

Supports controlled and uncontrolled open state and disabled items.

Behavior

Opening positions the menu at its trigger; outside interaction and Escape dismiss it.

Interaction

Arrow keys, Home, End, Enter, Space, and Escape follow menu conventions.

Accessibility

Uses native buttons with menu/menuitem roles and restores focus to the trigger.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose idiomatic composition over the same interaction contract.

CSR and SSR

Imports are server safe; positioning and dismissal begin only in the browser.

Testing guidance

Test opening, arrow navigation, selection, dismissal, focus restoration, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared contract.
