ContextMenu exposes commands from a context-menu invocation while preserving accessible menu semantics and keeping application command logic outside the library.

Overview

Use ContextMenu for secondary commands associated with an authored region. It composes shared menu semantics and dismissal behavior rather than introducing a separate command runtime.

Installation and imports

Import ContextMenu from the framework-specific /context-menu subpath and load @vyrnforge/web/styles/context-menu.css.

Quick start

Anatomy

Root, Trigger, Content, and Item form the public composition. Consumers provide command labels, disabled state, and application callbacks.

State

Open state may be framework-idiomatic controlled or uncontrolled where supported. Command execution state remains consumer-owned.

Behavior

The native contextmenu gesture opens the command surface. Escape, selection, and configured outside dismissal close it without creating a global overlay manager.

Interaction

Menu items support menu keyboard navigation and disabled items are skipped. Focus returns to the invoking context when dismissal requires restoration.

Accessibility

Content uses menu semantics and items use menuitem semantics. Consumers provide clear command names and must not hide primary or required actions exclusively behind a context-menu gesture.

Forms

ContextMenu is not form-associated. Menu action elements use non-submitting button behavior unless a consumer deliberately composes another native semantic.

Styling

Canonical CSS is owned by @vyrnforge/web, uses shared tokens, and is shared across framework ports. Product-specific command content should compose within the public anatomy.

Framework API

React and Vue expose idiomatic components, Angular exposes standalone directives, and Elements exposes an explicitly registered custom element. The same conceptual contract applies across ports.

CSR and SSR

Imports are server safe and browser listeners, positioning, focus, and dismissal behavior attach only after rendering.

Do / Don't

Do use ContextMenu for optional contextual commands. Don't make it the only path to essential functionality or place routing, permissions, or domain command dispatch inside VyrnForge.

Testing guidance

Test native context invocation, menu keyboard navigation, disabled items, selection, Escape and outside dismissal, focus restoration, SSR-safe imports, and automated accessibility checks.

Compatibility

React, Angular, Vue, and Elements implement sibling ContextMenu ports with Web-owned styling and shared lower-layer interaction capabilities.
