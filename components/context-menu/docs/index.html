ContextMenu exposes commands from a context-menu invocation while preserving accessible menu semantics.

Overview

Use ContextMenu for secondary commands associated with an authored region.

Installation and imports

Import from the /context-menu subpath and load its Web stylesheet.

Quick start

Anatomy

Root, Trigger, Content, and Item.

Behavior

The native contextmenu gesture opens the command surface; Escape and selection dismiss it.

Accessibility

Content uses menu semantics and disabled items remain unavailable.

CSR and SSR

Imports are server safe and browser listeners attach only after rendering.

Testing guidance

Test context invocation, keyboard dismissal, selection, SSR, and axe.
