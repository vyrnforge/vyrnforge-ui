Switch is a checkbox-backed native boolean setting exposed with role=switch.

Overview

Use Switch for one on/off setting. Checked state, keyboard activation, disabled state, form submission, and reset remain native.

Installation and imports

Load @vyrnforge/web/styles/switch.css. React, Angular, and Vue use their /switch entrypoints; Native Web uses data-vf-switch.

Quick start

Accessibility

Provide an accessible label and keep the checkbox-backed checked state synchronized with the switch semantics.

Styling

Canonical switch styling is owned by the Web package and uses shared tokens while the underlying checkbox remains the semantic and form-control source of truth.

Framework API

React and Vue expose Switch; Angular decorates input[vfSwitch]. The public contract uses native checked, disabled, name, value, and form semantics with role="switch".

Compatibility

Switch depends on native checkbox behavior plus the standardized switch role. Visual treatment is VyrnForge-owned, while activation and form behavior remain native across supported browsers.

Layer boundary

Switch owns one boolean value; switch groups and coordinated settings belong above Layer 2.
