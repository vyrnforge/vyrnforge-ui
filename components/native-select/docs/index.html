NativeSelect styles a native <select> without introducing custom popup or collection behavior.

Overview

Use NativeSelect when browser-owned option selection and popup behavior are appropriate.

Installation and imports

Load @vyrnforge/web/styles/native-select.css. React, Angular, and Vue use their /native-select entrypoints; Native Web uses data-vf-native-select.

Quick start

Accessibility

Provide an accessible label and preserve native option, disabled, required, keyboard, focus, and form behavior.

Layer boundary

Custom Select, Combobox, and Autocomplete own popup and collection behavior and belong to higher layers.
