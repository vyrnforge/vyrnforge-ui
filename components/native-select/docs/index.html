NativeSelect styles a native <select> without introducing custom popup or collection behavior.

Overview

Use NativeSelect when browser-owned option selection and popup behavior are appropriate.

Installation and imports

Load @vyrnforge/web/styles/native-select.css. React, Angular, and Vue use their /native-select entrypoints; Native Web uses data-vf-native-select.

Quick start

Accessibility

Provide an accessible label and preserve native option, disabled, required, keyboard, focus, and form behavior.

Styling

Canonical select styling lives in the Web package and uses shared tokens around the native control. The browser-owned popup and option rendering are not replaced by custom collection UI.

Framework API

React and Vue expose NativeSelect; Angular decorates select[vfNativeSelect]. Options remain authored with native <option> and <optgroup> elements.

Compatibility

Popup appearance and some option rendering details vary by browser and operating system. Selection, keyboard interaction, validation, and form submission remain standard native behavior.

Layer boundary

Custom Select, Combobox, and Autocomplete own popup and collection behavior and belong to higher layers.
