Presence / ExitLifecycle is Layer 4 infrastructure for retaining content during a consumer-controlled exit transition.

Overview

Use Presence when a later component needs to remain mounted after its present state becomes false so an exit transition can finish safely.

Installation and imports

Framework entrypoints are @vyrnforge/react/presence, @vyrnforge/angular/presence, @vyrnforge/vue/presence, and @vyrnforge/elements/presence.

Quick start

Anatomy

Presence exposes mounted state, an entered/exiting lifecycle state, and explicit exit completion.

Variants and sizes

Presence has no visual variants or sizes.

State

The lifecycle states are entered, exiting, and exited. Exiting remains mounted until the consumer calls the explicit completion operation.

Behavior

Changing present from true to false moves to exiting without unmounting. Completing exit moves to exited and permits unmounting/hiding.

Interaction

Presence adds no keyboard, focus, pointer, or dismissal behavior.

Accessibility

The consuming component must ensure exiting content does not remain interactable or exposed longer than intended. Presence itself adds no role or ARIA.

Forms

Presence owns no form state. Consumers decide whether exiting form controls remain active during transition.

Styling

Presence owns no motion CSS or timing tokens. Consumers use the lifecycle state with the shared motion/token foundation.

Framework API

React and Vue expose usePresence; Angular exposes structural vfPresence with lifecycle context; Elements exposes vf-presence and explicit completeExit().

CSR and SSR

Imports and entered rendering are server-safe. Exit coordination begins only after committed client state changes.

Examples

The basic example demonstrates entered, exiting, and explicit completion.

Do / Don't

Do keep exit timing and animation implementation outside Presence. Don't turn Presence into a generic state-machine or overlay controller.

Testing guidance

Test entered rendering, retained exiting content, explicit completion, SSR safety, rapid re-entry, and consuming-component accessibility.

Compatibility

Presence is a Layer 4 port primitive for React, Angular, Vue, and Elements. Native Web authors can coordinate equivalent lifecycle with ordinary DOM ownership when needed.
