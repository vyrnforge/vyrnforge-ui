Select exposes one chosen value from a floating listbox.

Overview

Use Select when a compact trigger should open authored options and only one value may be selected.

Installation and imports

Import from the framework-specific /select subpath and load @vyrnforge/web/styles/select.css.

Quick start

Anatomy

Root, Trigger, Content, and Option form the public composition.

State

Selected value and popup open state may be controlled or uncontrolled according to the framework port.

Behavior

Selection replaces the current value, closes the popup, and uses shared lower-layer navigation and selection behavior.

Interaction

The trigger opens the popup; keyboard navigation moves through enabled options; Escape and outside interaction dismiss it.

Accessibility

The trigger declares a listbox popup and options expose option and aria-selected semantics with an authored accessible name.

Forms

Consumers own name, serialization, required state, and validation policy for the selected value.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same trigger/listbox relationship idiomatically for their ecosystem.

CSR and SSR

Imports are server safe; floating positioning, focus, and dismissal start only in the browser.

Do / Don't

Do use for compact single selection. Don't use it as a routing, remote-data, or domain workflow abstraction.

Testing guidance

Test opening, keyboard navigation, selection, disabled options, dismissal, focus restoration, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling Select ports with Web-owned canonical styling.
