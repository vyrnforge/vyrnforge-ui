SplitButton preserves a primary action while exposing related secondary commands from a separate menu trigger.

Overview

Use SplitButton when one action is dominant and alternatives remain closely related.

Installation and imports

Import from /split-button and load its Web stylesheet plus Menu styling.

Quick start

Anatomy

Root, Action, Trigger, Content, and Item.

Behavior

The primary action never opens the menu; the adjacent trigger exclusively controls secondary commands.

Accessibility

Both controls are native buttons and the menu trigger exposes popup state independently.

Testing guidance

Test primary activation independence, menu keyboard behavior, SSR, and axe.
