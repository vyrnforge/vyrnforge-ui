Radio is one native radio input, not a collection manager.

Overview

Use Radio for an individual input[type=radio]. Native name grouping and form behavior remain browser-owned.

Installation and imports

Load @vyrnforge/web/styles/radio.css. React, Angular, and Vue use their /radio entrypoints; Native Web uses data-vf-radio.

Quick start

Accessibility

Provide an accessible label and preserve native grouping, keyboard, checked, disabled, and form semantics.

Layer boundary

Managed RadioGroup focus and collection coordination belong above Layer 2.
