ToggleButton is a native button with one persistent aria-pressed state.

Overview

Use ToggleButton when one button toggles a persistent pressed state without coordinating a collection or popup.

Installation and imports

Load @vyrnforge/web/styles/toggle-button.css. React, Angular, and Vue use their /toggle-button entrypoints. Native Web additionally uses connectToggleButton from @vyrnforge/web/toggle-button.

Quick start

Accessibility

The semantic source of truth is a native button with aria-pressed="true|false". Native keyboard activation and disabled behavior are preserved.

Framework API

React and Vue support controlled and uncontrolled pressed state. Angular exposes pressed as a model. Consumer click handlers run before VyrnForge changes pressed state and may cancel the transition.

Layer boundary

Toggle groups and segmented controls coordinate multiple controls and belong above Layer 2.
