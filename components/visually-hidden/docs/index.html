VisuallyHidden keeps meaningful content in the accessibility tree while removing it from ordinary visual presentation.

Shared foundation

import '@vyrnforge/web/styles/foundation.css';

The canonical hiding recipe is shared foundation CSS. @vyrnforge/web/styles/visually-hidden.css is a granular alias to that same foundation, not a second implementation.

Native semantics

Choose the correct native element and apply data-vf-visually-hidden. The primitive never adds aria-hidden, hidden, inert, display:none, or visibility:hidden.

Frameworks

React and Vue provide native-element convenience components and Angular provides a directive. Native Web is the Elements surface because a custom element adds no semantic value.
