FileUploader composes native file selection, an accessible drop target, and an authored file list without taking ownership of upload transport.

Overview

Use FileUploader to collect local files before consumer-owned upload handling.

Installation and imports

Import from each framework's /file-uploader subpath and load @vyrnforge/web/styles/file-uploader.css.

Quick start

Anatomy

Root, native file input, dropzone, and file list.

Variants and sizes

No transport-specific variants.

State

Tracks the locally selected files for presentation.

Behavior

Clicking the dropzone delegates to the native input and dropping files emits the local file set.

Interaction

The dropzone is keyboard-focusable and the file input remains native.

Accessibility

Consumers must provide clear instructions and any validation feedback.

Forms

Submission and network upload remain consumer responsibilities.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports preserve the same anatomy with idiomatic event surfaces.

CSR and SSR

Imports are server safe; File objects are only handled after browser interaction.

Examples

The basic example lists a selected file.

Do / Don't

Do use for local file acquisition. Don't embed storage providers, upload endpoints, or business permissions.

Testing guidance

Test native selection, drop behavior, semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
