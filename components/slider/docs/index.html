Slider is one native single-thumb input[type=range].

Overview

Use Slider for one numeric value in a bounded range. Native keyboard behavior, value constraints, focus, and form semantics remain browser-owned.

Installation and imports

Load @vyrnforge/web/styles/slider.css. React, Angular, and Vue use their /slider entrypoints; Native Web uses data-vf-slider.

Quick start

Accessibility

Provide an accessible name and meaningful min, max, step, and current value constraints.

Styling

Canonical slider styling is owned by the Web package and uses shared tokens while keeping the real range input as the interaction and focus target.

Framework API

React and Vue expose Slider; Angular decorates input[vfSlider]. Value, min, max, step, disabled, and form behavior remain native range-input contracts.

Compatibility

Track and thumb rendering differ across browser engines and operating systems. VyrnForge preserves native keyboard and value semantics instead of replacing the control with a custom slider runtime.

Layer boundary

Multi-thumb RangeSlider coordinates multiple values and belongs above Layer 2.
