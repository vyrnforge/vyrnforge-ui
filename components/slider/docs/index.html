Slider is one native single-thumb input[type=range].

Overview

Use Slider for one numeric value in a bounded range. Native keyboard behavior, value constraints, focus, and form semantics remain browser-owned.

Installation and imports

Load @vyrnforge/web/styles/slider.css. React, Angular, and Vue use their /slider entrypoints; Native Web uses data-vf-slider.

Quick start

Accessibility

Provide an accessible name and meaningful min, max, step, and current value constraints.

Layer boundary

Multi-thumb RangeSlider coordinates multiple values and belongs above Layer 2.
