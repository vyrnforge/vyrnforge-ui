ColorInput is the native browser color-selection control.

Overview

Use ColorInput when browser-owned input[type=color] behavior is sufficient.

Installation and imports

Load @vyrnforge/web/styles/color-input.css. React, Angular, and Vue use their /color-input entrypoints; Native Web uses data-vf-color-input.

Quick start

Accessibility

Provide an accessible label and preserve native focus, disabled, value, and form semantics.

Styling

Canonical styling is owned by the Web package and uses shared tokens around the native color control. Browser-owned picker chrome is not replaced or normalized into a custom popup.

Framework API

React and Vue expose ColorInput; Angular decorates input[vfColorInput]. Native Web uses a real input[type=color] with the shared data hook.

Compatibility

The control depends on each browser and operating system's native color-input implementation, so picker appearance and interaction details may vary while the value and form contract remain native.

Layer boundary

A composite ColorPicker with popup, palettes, or coordinated fields belongs to a higher layer.
