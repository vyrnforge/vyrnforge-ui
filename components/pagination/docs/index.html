Pagination provides accessible navigation relationships for authored page links without owning routing, fetching, or result state.

Overview

Use Pagination to present navigation between known result pages.

Installation and imports

Import from each framework's /pagination subpath and load @vyrnforge/web/styles/pagination.css.

Quick start

Anatomy

Navigation root, page items, previous, and next links.

Variants and sizes

No routing-specific variants.

State

The current page is expressed with aria-current.

Behavior

Navigation is delegated to authored links and consumer routing.

Interaction

Items remain native links.

Accessibility

The root is a named navigation landmark and the current page is announced.

Forms

Not form-associated.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same landmark and link anatomy idiomatically.

CSR and SSR

Imports are server safe and links render without client state.

Examples

The basic example marks page two as current.

Do / Don't

Do use for page navigation. Don't make the library own routes, queries, or pagination data.

Testing guidance

Test landmark naming, current-page semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
