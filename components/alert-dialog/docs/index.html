AlertDialog presents an interruptive modal decision that requires an explicit user response.

Overview

Use AlertDialog for destructive or consequential confirmation.

Installation and imports

Import the framework /alert-dialog subpath and Web CSS.

Quick start

Anatomy

Root, Title, Description, Body, Cancel, Action.

Variants and sizes

No semantic variants.

State

Controlled or uncontrolled open state.

Behavior

Uses Dialog modality but prevents backdrop dismissal.

Interaction

Escape may request dismissal; decision controls are explicit.

Accessibility

Uses alertdialog semantics, labelled title/description, native modality and focus restoration.

Forms

Consumers choose form semantics for authored actions.

Styling

Web-owned Dialog-derived CSS.

Framework API

Ports compose the shared Dialog contract.

CSR and SSR

Imports are server safe; modal activation is client-only.

Examples

Basic confirmation.

Do / Don't

Do reserve for consequential decisions; don't use for ordinary information.

Testing guidance

Test labeling, modality, dismissal policy, focus restoration, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements.
