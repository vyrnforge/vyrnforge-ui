Popover is a dismissible anchored surface for contextual interactive content.

Overview

Use Popover for contextual controls or information anchored to a trigger.

Installation and imports

Import /popover and Web CSS.

Quick start

Anatomy

Root, Trigger, Content.

Variants and sizes

Placement is controlled through L4 floating positioning.

State

Controlled/uncontrolled open state.

Behavior

Positions relative to a trigger and dismisses on Escape or outside pointer.

Interaction

Trigger uses native button activation; content can contain interactive descendants.

Accessibility

Trigger exposes expanded/control relationships; content defaults to dialog semantics.

Forms

Trigger is type=button.

Styling

Canonical Web CSS with token-driven elevation.

Framework API

Ports compose L4 floating, dismissal, and portal capabilities.

CSR and SSR

Imports are SSR safe; browser positioning activates after commit.

Examples

Basic anchored popover.

Do / Don't

Do use for contextual interactive surfaces; don't use for modal workflows.

Testing guidance

Test trigger relationships, placement, dismissal, focus, SSR, and axe.

Compatibility

React, Angular, Vue, Elements.
