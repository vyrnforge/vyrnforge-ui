Checkbox is a native boolean selection control with explicit support for the DOM-only indeterminate state.

Overview

Checked state, keyboard activation, form submission, validation, and reset remain native. Indeterminate is synchronized as an element property rather than invented as a third submitted value.

Installation and imports

Load @vyrnforge/web/styles/checkbox.css. React, Angular, and Vue use their /checkbox entrypoints; Native Web uses data-vf-checkbox.

Quick start

Accessibility

Provide an accessible label. Preserve native checked and disabled semantics; use indeterminate only to communicate partial selection.

Styling

Canonical checkbox styling lives in the Web package and is token-driven. Keep the native input available to focus and assistive technology; do not replace it with a purely visual proxy.

Framework API

React and Vue expose Checkbox; Angular decorates input[vfCheckbox]. The indeterminate API synchronizes the DOM property while checked state remains the native submitted value.

Compatibility

Checkbox relies on native checkbox semantics supported by modern browsers. The indeterminate state is visual and accessibility state only and is not submitted as a third form value.

Layer boundary

CheckboxGroup coordinates multiple controls and belongs above Layer 2.
