Rating captures one discrete score using radio-group semantics with a visual rating presentation.

Overview

Use Rating when users choose one value from a small ordered score range.

Installation and imports

Import from the framework-specific /rating subpath and load @vyrnforge/web/styles/rating.css.

Quick start

Anatomy

Root and score Items compose the ordered choice group.

State

One numeric score is selected; consumers may control the value through the framework port.

Behavior

Activating an enabled score selects that value and clears peer selection.

Interaction

Keyboard behavior follows radio-group selection expectations.

Accessibility

The group exposes radiogroup semantics and every score has an explicit accessible label and checked state.

Forms

Consumers own form naming, required state, serialization, and validation.

Styling

Canonical CSS is Web-owned and token driven; visual symbols must not replace accessible labels.

Framework API

Ports expose the same ordered discrete-score contract idiomatically.

CSR and SSR

Imports are server safe and selected state renders deterministically.

Do / Don't

Do use for discrete ratings. Don't make VyrnForge own score meaning, persistence, or product analytics.

Testing guidance

Test keyboard behavior, checked state, disabled items, labels, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling Rating ports.
