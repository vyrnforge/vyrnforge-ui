Icon

Icon is VyrnForge's non-interactive SVG primitive. The initial foundation ships one sample glyph, bookmarkIcon, to prove the contract before the catalog grows.

Visual axes

variant is outlined or filled. shape is rounded or sharp. They are independent axes, with outlined + rounded as the default.

Accessibility

Icons are decorative by default and are hidden from assistive technology. Set label only when the icon itself carries standalone meaning. Inside an icon-only button, the Button owns the accessible name and the Icon remains decorative.

Styling

Icons inherit currentColor. Sizes are sm, md, and lg. Load @vyrnforge/web/styles/icon.css explicitly, or use the aggregate Web stylesheet.

Definitions

SVG-specific icon definitions live in @vyrnforge/web/icon. This initial slice does not introduce a registry or a separate icon package. New glyphs can be added as authored definitions later.

Elements

vf-icon uses explicit registration. Its rich icon definition is a property; serializable presentation choices use attributes.
