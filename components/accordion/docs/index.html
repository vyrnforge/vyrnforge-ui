Accordion coordinates multiple disclosure items with optional single or multiple expansion and composite keyboard movement.

Overview

Use Accordion for a related set of expandable sections.

Installation and imports

Use each framework's /accordion subpath and Web CSS.

Quick start

Anatomy

Root, Item, Header, Trigger, Panel.

Variants and sizes

Single and multiple expansion modes.

State

Controlled/uncontrolled value, disabled items, optional single-mode collapse.

Behavior

Coordinates expansion without owning application state.

Interaction

Native activation plus Arrow Up/Down, Home, and End trigger navigation.

Accessibility

Headers contain native buttons with aria-expanded/controls; panels use labelled regions.

Forms

Triggers do not submit forms.

Styling

Web owns canonical token-driven CSS.

Framework API

Ports preserve the shared item/value contract idiomatically.

CSR and SSR

Imports are SSR safe.

Examples

Basic single accordion.

Do / Don't

Do use for related disclosures; don't use for unrelated navigation.

Testing guidance

Test value modes, disabled skipping, keyboard navigation, relationships, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements.
