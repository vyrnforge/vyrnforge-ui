Listbox presents a keyboard-navigable set of options with single or multiple selection.

Overview

Use Listbox when options remain visible rather than opening from a trigger.

Installation and imports

Import from /listbox and load its Web stylesheet.

Quick start

Interaction

Arrow keys, Home, End, typeahead, Enter, and Space operate enabled options.

Accessibility

Uses listbox/option semantics, aria-selected, and aria-multiselectable when required.

Testing guidance

Test selection modes, keyboard navigation, disabled options, SSR, and axe.
