Listbox presents a keyboard-navigable set of options with single or multiple selection.

Overview

Use Listbox when options remain visible rather than opening from a trigger.

Installation and imports

Import from the framework-specific /listbox subpath and load @vyrnforge/web/styles/listbox.css.

Quick start

Anatomy

Root and Option form the public composition; consumers author values, text, labels, and disabled state.

State

Supports single or multiple selected values with framework-idiomatic controlled or uncontrolled ownership where available.

Behavior

Selection uses shared selection operations and enabled-option navigation rather than a component-specific selection engine.

Interaction

Arrow keys, Home, End, typeahead, Enter, and Space operate enabled options.

Accessibility

Uses listbox/option semantics, aria-selected, and aria-multiselectable when required; consumers provide an accessible name.

Forms

Listbox is not inherently form-associated; consumers own serialization, validation, and submission policy.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

React and Vue expose components, Angular exposes standalone directives, and Elements exposes explicit registration for the same conceptual contract.

CSR and SSR

Imports are server safe; browser focus and typeahead behavior starts after rendering.

Do / Don't

Do use for visible option selection. Don't make the library own product data, permissions, or remote loading.

Testing guidance

Test selection modes, keyboard navigation, typeahead, disabled options, SSR-safe imports, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling Listbox ports using shared lower-layer capabilities.
