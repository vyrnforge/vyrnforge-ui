L3 provides ten focused composition primitives for spatial arrangement, form composition, and control relationships without becoming an application or behavioral-widget layer.

Compose with the platform.VyrnForge supplies shared intent, tokens, semantics, and portable CSS while leaving specialized Grid/Flexbox work, native form behavior, routing, application state, and validation engines to their proper owners.

Overview

Spatial composition

Stack, Inline, Cluster, Grid, Container, and AspectRatio.

Form composition

Field, Fieldset, and InputGroup.

Control relationship

RadioGroup groups related native radios and orientation without owning selection state.

Quick start

Load @vyrnforge/web/styles/layout.css once. The same canonical CSS contract is consumed by Native Web, React, Angular, Vue, and Elements.

Spatial composition

Stack is block-axis flow. Inline is a single non-wrapping inline row. Cluster is inline flow that wraps. Grid creates intrinsic repeated-item tracks. Container owns content bounds and logical gutters. AspectRatio reserves a stable preset ratio.

Inline versus Cluster

<div data-vf-inline data-vf-inline-gap="sm">…</div>
<div data-vf-cluster data-vf-cluster-gap="sm">…</div>

Inline never wraps; Cluster wraps as space runs out.

AspectRatio

<div data-vf-aspect-ratio data-vf-aspect-ratio-value="video">…</div>

Presets: square, video, landscape, and portrait.

Grid

Grid uses equal flexible tracks and auto-fit. Its public framework API exposes only gap; override --vf-grid-min-item-size when a repeated-item family needs another minimum. Use ordinary CSS Grid for named areas, explicit placement, spanning, or tracks with different meanings.

Form composition

Field spatially relates authored label, control, and supporting content. It does not generate IDs, labels, descriptions, validation state, or error messages.

Fieldset preserves native <fieldset>/<legend> semantics in React, Angular, Vue, and Native Web. The Elements sibling port exposes an equivalent named group relationship because a custom-element host cannot become a native fieldset.

InputGroup visually joins adjacent controls but does not merge values, focus, validation, or disabled state.

RadioGroup

RadioGroup owns grouping and layout only. Native radios continue to own checked behavior through their shared name. React, Angular, Vue, and Native Web use fieldset/legend semantics; Elements uses the equivalent named radiogroup relationship and reflects aria-orientation.

Spacing

The shared LayoutSpace vocabulary is none, xs, sm, md, lg, xl, 2xl, and 3xl. Composition primitives consume semantic spacing tokens instead of arbitrary JavaScript pixel props.

Accessibility and boundaries

Spatial primitives do not invent ARIA or alter source order. Form/control relationship primitives use native grouping where possible and equivalent explicit relationships where custom-element hosts require them. L3 does not own keyboard widgets, selection controllers, routing, permissions, application state, validation engines, or app-shell behavior.

Compatibility

The ten exported L3 concepts, their documented data/Elements attributes, the shared spacing vocabulary, ratio/orientation values, and --vf-grid-min-item-size are public compatibility commitments. Ordinary CSS remains the extension mechanism for needs outside these focused contracts.
