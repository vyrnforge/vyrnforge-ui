Separator is a native-first Layer 1 primitive for meaningful boundaries between adjacent content groups.

Native first

Use the native hr element with VyrnForge hooks. Horizontal is the default; vertical separators expose aria-orientation="vertical".

Styling

import '@vyrnforge/web/styles/separator.css';

The stylesheet uses shared semantic border tokens, logical properties, low-specificity selectors, and forced-colors support.

Frameworks

React and Vue render hr; Angular decorates an authored hr. Native Web is the Elements surface because a custom element would add no semantic value.

Boundary

Separator does not own spacing, arbitrary dimensions, visual variants, responsive layout, focus, keyboard handling, or behavior state.
