OTPField composes a short sequence of native inputs for one-time codes without owning authentication, delivery, verification, expiry, resend, or retry workflows.

Overview

Use OTPField for short verification-code entry when the application/provider owns the surrounding workflow.

Installation and imports

Import from each framework's /otp-field subpath and load @vyrnforge/web/styles/otp-field.css.

Quick start

Anatomy

Consumer-authored named root group and indexed native inputs.

Variants and sizes

Length is configurable; visual sizes remain token-driven.

State

React, Angular, and Vue support controlled/uncontrolled value patterns idiomatically; Elements exposes a value property and bubbling valuechange event. Verification truth remains external.

Behavior

Single-character entry advances focus. Multi-character input on the first one-time-code cell and paste distribute characters across remaining cells. Empty Backspace returns focus to the previous cell.

Interaction

Each cell remains a native input. The first cell defaults to autocomplete="one-time-code" and accepts up to the field length so platform autofill can deliver a complete code; later cells default to autocomplete="off" and one character.

Accessibility

The root exposes group semantics but no synthesized accessible name. Consumers must author the localized group name and each cell name; no port invents English positional wording.

Forms

Verification, expiry, transport, resend, retry, rate limits, and provider errors remain consumer/provider responsibilities.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports implement the same authored-name and input-assistance concept idiomatically. React and Vue expose root/input components, Angular exposes root/input directives, and Elements upgrades authored native inputs.

CSR and SSR

Imports are server safe. Server rendering does not establish verification truth.

Examples

The basic example authors a four-cell verification-code group and all cell names.

Do / Don't

Do author localized group/cell names and preserve native one-time-code assistance. Don't embed code delivery, verification, expiry, resend, provider policy, or security claims into OTPField.

Testing guidance

Test authored names, one-time-code metadata, single-entry focus progression, multi-character platform input, paste distribution, empty Backspace, value assembly, SSR, package entrypoints, and axe.

Compatibility

React, Angular, Vue, and Elements implement the same declared assistance contract. Consumers migrating from the earlier rebuild API must author group/cell accessible names instead of relying on synthesized English fallbacks.
