OTPField composes a short sequence of one-character inputs for one-time codes without owning authentication or verification workflows.

Overview

Use OTPField for short verification-code entry.

Installation and imports

Import from each framework's /otp-field subpath and load @vyrnforge/web/styles/otp-field.css.

Quick start

Anatomy

Root group and indexed one-character inputs.

Variants and sizes

Length is configurable; visual sizes remain token-driven.

State

Supports controlled and uncontrolled code value.

Behavior

Entry advances focus and empty backspace can return focus to the previous cell.

Interaction

Each cell remains a native input.

Accessibility

The root is a named group and every cell exposes its position.

Forms

Verification, expiry, transport, and error policy remain consumer responsibilities.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports implement the same value and indexed-input contract.

CSR and SSR

Imports are server safe.

Examples

The basic example uses a four-digit code.

Do / Don't

Do use for short codes. Don't embed authentication services or retry policy.

Testing guidance

Test focus progression, labels, value assembly, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
