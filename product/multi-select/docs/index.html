MultiSelect chooses several values from a compact floating listbox.

Overview

Use MultiSelect when several authored options must be selected from a popup while conserving space.

Installation and imports

Import from the framework-specific /multi-select subpath and load @vyrnforge/web/styles/multi-select.css.

Quick start

Anatomy

Root, Trigger, Content, and Option compose a multi-value popup selector.

State

Selected values and open state may be controlled or uncontrolled according to the framework port.

Behavior

Option activation toggles membership using shared selection operations and preserves other selected values.

Interaction

The trigger opens the listbox; keyboard navigation operates enabled options; Escape and outside interaction dismiss the surface.

Accessibility

The popup uses listbox semantics with aria-multiselectable and each option exposes aria-selected.

Forms

Consumers own form serialization, naming, required policy, and validation for the selected value array.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose idiomatic state/event APIs while preserving the same conceptual anatomy.

CSR and SSR

Imports are server safe; popup positioning, focus, and dismissal are browser-only concerns.

Do / Don't

Do use for compact multi-value selection. Don't make the component own remote data, product filters, or persistence.

Testing guidance

Test independent option toggling, keyboard navigation, dismissal, focus, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling MultiSelect ports using shared lower-layer selection behavior.
