Tooltip provides brief non-interactive descriptive text for a trigger on hover or focus.

Overview

Use Tooltip for concise supplemental descriptions.

Installation and imports

Import /tooltip and Web CSS.

Quick start

Anatomy

Root, Trigger, Content.

Variants and sizes

Placement and open/close delays are configurable.

State

Controlled/uncontrolled visibility.

Behavior

Opens on hover/focus, closes on leave/blur, and uses L4 positioning.

Interaction

Tooltip content is non-interactive and does not take focus.

Accessibility

Trigger references role=tooltip content with aria-describedby.

Forms

No form state.

Styling

Web-owned token-driven tooltip CSS.

Framework API

Ports expose Root, Trigger, Content.

CSR and SSR

SSR-safe imports; timers/positioning are client-only.

Examples

Basic tooltip.

Do / Don't

Do keep content short; don't put buttons or essential-only information inside.

Testing guidance

Test hover/focus, delays, describedby, SSR, and axe.

Compatibility

React, Angular, Vue, Elements.
