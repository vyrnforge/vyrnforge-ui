Carousel navigates a bounded sequence of authored slides without owning product content or routing.

Overview

Carousel is a Layer 5 composite built from accepted lower-layer semantics and behavior.

Installation and imports

Import from each framework's /carousel subpath and load @vyrnforge/web/styles/carousel.css.

Quick start

Anatomy

Root, viewport, slides, previous, and next controls.

Variants and sizes

No application-specific variants are owned.

State

Supports local or controlled active index.

Behavior

Navigation stays within the authored slide set.

Interaction

Previous and next remain native buttons.

Accessibility

The root is an accessible carousel region and slides expose group semantics.

Forms

Navigation controls use type=button.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose idiomatic sibling implementations of the same anatomy.

CSR and SSR

Imports are server safe; browser behavior starts after rendering.

Examples

The basic example demonstrates two slides.

Do / Don't

Do use for bounded authored content. Don't use as a router.

Testing guidance

Test navigation, disabled boundaries, semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
