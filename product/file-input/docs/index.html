FileInput is native file selection without upload orchestration.

Overview

Use FileInput for a browser-owned input[type=file]. File chooser behavior, selected-file exposure, focus, disabled state, and form semantics remain native.

Installation and imports

Load @vyrnforge/web/styles/file-input.css. React, Angular, and Vue use their /file-input entrypoints; Native Web uses data-vf-file-input.

Quick start

Accessibility

Provide an accessible label and use native accept, multiple, required, and disabled attributes where appropriate.

Styling

Shared Web CSS styles the native file input without replacing its chooser semantics. Preserve the real input so keyboard, assistive technology, and browser security behavior remain intact.

Framework API

React and Vue expose FileInput; Angular decorates input[vfFileInput]. File selection remains available through the native input and files property.

Compatibility

File chooser UI is owned by the browser and operating system and may vary. Programmatic file-path control remains intentionally unavailable because the native security model is preserved.

Layer boundary

Upload queues, drag/drop, progress, retry, and workflow state belong to FileUploader or Dropzone at higher layers.
