TemporalInput exposes the native date and time input family without composite picker behavior.

Overview

Supported types are date, time, datetime-local, month, and week. Browser editing, validation, picker UI, and form behavior remain native.

Installation and imports

Load @vyrnforge/web/styles/temporal-input.css. React, Angular, and Vue use their /temporal-input entrypoints; the shared type vocabulary is available from @vyrnforge/web/temporal-input.

Quick start

Accessibility

Provide an accessible label and preserve native min, max, step, required, disabled, readonly where supported, and validation semantics.

Styling

Canonical TemporalInput styling is owned by the Web package and uses shared tokens around the native input. Browser-owned picker UI is intentionally not replaced by a custom calendar or time selector.

Framework API

React and Vue expose TemporalInput; Angular decorates input[vfTemporalInput]. The public type contract is restricted to the supported temporal input types.

Compatibility

Picker UI and editing affordances vary across browser engines and operating systems, especially for month and week inputs. Consumers should rely on native value, validation, and form semantics rather than identical picker presentation.

Layer boundary

DatePicker and TimePicker are composite widgets and belong to higher layers.
