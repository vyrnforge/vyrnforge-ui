ColorPicker composes native color input, text entry, and swatch presentation without introducing application-specific color workflows.

Overview

Use ColorPicker when consumers need synchronized native and textual color entry.

Installation and imports

Import from each framework's /color-picker subpath and load @vyrnforge/web/styles/color-picker.css.

Quick start

Anatomy

Root, native color input, text input, and swatch.

Variants and sizes

No semantic variants or sizes.

State

Supports controlled and uncontrolled color value.

Behavior

Valid six-digit hexadecimal text synchronizes the authored controls.

Interaction

Relies on native input behavior.

Accessibility

Inputs remain native form controls with authored accessible names.

Forms

Consumers retain ownership of names, submission, and validation policy.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

All ports expose the same component concept idiomatically.

CSR and SSR

Imports are server safe.

Examples

The basic example shows synchronized input and swatch presentation.

Do / Don't

Do use for color selection. Don't embed product-specific palettes or persistence.

Testing guidance

Test synchronization, native semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
