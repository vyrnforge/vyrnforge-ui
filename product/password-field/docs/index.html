PasswordField composes a native password input with an explicit visibility control while leaving validation, strength policy, and authentication to consumers.

Overview

Use PasswordField when users benefit from toggling password visibility.

Installation and imports

Import from each framework's /password-field subpath and load @vyrnforge/web/styles/password-field.css.

Quick start

Anatomy

Root, native input, and visibility toggle.

Variants and sizes

No password-policy variants.

State

Visibility is local presentation state; input value remains native.

Behavior

The toggle switches the input between password and text presentation.

Interaction

The toggle remains a native button.

Accessibility

The toggle exposes pressed state and a changing accessible name.

Forms

Consumers own name, autocomplete, required state, validation, and submission.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same input/toggle relationship idiomatically.

CSR and SSR

Imports are server safe.

Examples

The basic example toggles visibility without changing the value.

Do / Don't

Do use for password visibility. Don't embed authentication or password-strength policy.

Testing guidance

Test input type, toggle state/name, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
