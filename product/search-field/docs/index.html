SearchField composes native search input behavior with an explicit clear control without owning search execution, routing, or results.

Overview

Use SearchField for a query input with a clear affordance.

Installation and imports

Import from each framework's /search-field subpath and load @vyrnforge/web/styles/search-field.css.

Quick start

Anatomy

Search root, native search input, and clear button.

Variants and sizes

No result- or product-specific variants.

State

Supports controlled and uncontrolled query value.

Behavior

Clear resets the query and restores focus to the input.

Interaction

The input and clear control remain native controls.

Accessibility

The root is a search landmark and the clear button has an accessible name.

Forms

Consumers own submission, debouncing, validation, and result fetching.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same query and clear relationship idiomatically.

CSR and SSR

Imports are server safe.

Examples

The basic example demonstrates clearing an authored query.

Do / Don't

Do use for query entry. Don't make the library own search services or results.

Testing guidance

Test clear behavior, focus restoration, semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
