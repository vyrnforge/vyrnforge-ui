PreviewCard shows contextual preview content for a referenced item without becoming a modal workflow.

Overview

Use PreviewCard for richer hover/focus previews of links or referenced content.

Installation and imports

Import /preview-card and Web CSS.

Quick start

Anatomy

Root, Trigger, Content.

Variants and sizes

Placement is configurable through L4 floating positioning.

State

Controlled/uncontrolled visibility.

Behavior

Opens from hover/focus and remains available while pointer is over content.

Interaction

Does not impose modal focus behavior.

Accessibility

Trigger exposes control relationships; authored preview content must remain semantically meaningful.

Forms

No form state.

Styling

Web-owned token-driven elevated surface CSS.

Framework API

Ports expose Root, Trigger, Content and consume L4 positioning/dismissal.

CSR and SSR

SSR-safe imports; positioning begins only in a live browser.

Examples

Basic preview card.

Do / Don't

Do use for supplemental previews; don't hide essential workflow actions only inside hover.

Testing guidance

Test hover/focus persistence, dismissal, placement, SSR, and axe.

Compatibility

React, Angular, Vue, Elements.
