# Empty State

An Empty State explains why a region has no content and supplies an appropriate next action. It is a composition, not a new component or an automatic error.

## Usage and accessibility

Distinguish first use, no search results, permission limits, failure and genuinely empty data. Use an accessible heading, concise explanation, ordinary layout and a relevant action. Do not put the entire empty region in a live announcement or use empty paint to conceal a failure.

## Native Web

Use a section, heading, description and native action.

## React composition

Use the existing React components from their public entrypoints. Browser-aware bundlers load the shared Web CSS; no separate Empty State component is required.
