# Banner

A Banner is broad persistent information composed with Alert, in a predictable region of the affected page or service. It is not a second feedback renderer.

## Usage and accessibility

Place at the top of the affected scope; do not use it for field validation. Use explicit wording and only dismiss when durable rediscovery exists. Severity is separate from announcement. Avoid competing banners.

## Native Web

Compose the Alert Web styling hooks in an authored section.

## React composition

Use the existing React components from their public entrypoints. Browser-aware bundlers load the shared Web CSS; no separate Banner component is required.
