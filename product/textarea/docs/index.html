Textarea styles a native multiline text-entry control while preserving browser and form semantics.

Overview

Use Textarea for ordinary multiline text values. The browser remains responsible for editing, line breaks, selection, focus, value, resize, submission, reset, and constraint validation.

Installation and imports

Load @vyrnforge/web/styles/textarea.css. React, Angular, and Vue use their /textarea package entrypoints; Native Web and Custom Elements applications use data-vf-textarea on a native textarea.

Quick start

Accessibility

Always provide an accessible name. Prefer a native <label> when practical. Keep disabled, readonly, required, and invalid semantics distinct.

Styling

The stable styling hook is data-vf-textarea. Shared semantic tokens drive surface, text, border, focus, disabled, readonly, and invalid presentation without suppressing native resize behavior.

Framework API

React and Vue expose Textarea; Angular exposes vfTextarea. Native rows, cols, wrap, minlength, and maxlength remain available. No <vf-textarea> custom element is introduced.

Compatibility

The rebuild contract preserves native multiline and form behavior and uses the same canonical Web styling across implemented framework ports.
