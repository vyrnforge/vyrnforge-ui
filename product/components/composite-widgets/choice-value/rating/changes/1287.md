Rating now uses independent generated radio names in React and Vue unless the consumer supplies a form name. Angular requires a root name. Consumers author the group label and may supply localized item labels through getItemLabel or explicit items; numeric fallback labels replace English star strings. Native radio selection, form submission and keyboard behavior remain the baseline. Rating glyphs distinguish filled and unfilled values without relying on color alone. Elements and Web continue to use author-provided native radio names and labels.
