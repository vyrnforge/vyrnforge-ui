SegmentedControl now composes native radio inputs and labels instead of buttons with synthetic radio behavior. React and Vue generate independent group names by default; supply a root name for form submission. React item props and refs target the input, and children label the native control. Angular requires a root name and uses the item directive on an authored radio input inside a label. Web and Elements use native authored radio names and labels, with the styling marker on the label. Keyboard navigation, grouping, disabled behavior and submission are native. Controlled framework requests reconcile checked state with the committed value.
