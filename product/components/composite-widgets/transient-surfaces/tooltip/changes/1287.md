# L5 Tooltip — Elements native slice

Related: #1287, #1280.

- Elements uses native manual popover with the trigger as its implicit anchor. CSS owns placement and fallback; no new positioning runtime.
- Hover and focus are independent reasons to remain open; Escape dismisses without moving focus, and a fresh interaction can reopen.
- Preserve authored description IDs and existing description references. Generate a document-unique ID only when none is authored.
- No public TypeScript signature changes. This slice does not claim completion of the React, Angular, Vue, cross-browser or assistive-technology evidence.
