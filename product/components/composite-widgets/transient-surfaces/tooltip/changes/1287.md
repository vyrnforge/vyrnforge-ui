# L5 Tooltip native migration

Related: #1287, #1280.

- Runtime ports use native manual popover with the trigger as its implicit anchor. CSS owns placement and fallback. No new overlay or positioning runtime.
- Hover and focus independently preserve visibility; Escape dismisses without moving focus. Timer and document listener lifetime is component-owned.
- Content stays mounted while closed, preserving authored accessible description references and server-rendered relationships.
- React and Vue root `contentId` owns an optional authored content ID; move an ID formerly authored on the Content part to Root. Vue Trigger forwards to one native trigger instead of wrapping it in a span. This makes description and focus target the actual control.
- Angular follows Disclosure's explicit root ID pattern: supply a stable `id`, optionally `contentId`, and author any additional description references on the Trigger. Elements preserves an authored ID or allocates a document-unique ID when absent; SSR authoring requires IDs and relationships.
- Existing placement values are retained. Native top-layer positioning has no deliberate gap, so pointer traversal remains continuous. Cross-engine positioning, controlled rejection and manual AT evidence remain required.
