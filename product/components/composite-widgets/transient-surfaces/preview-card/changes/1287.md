# L5 PreviewCard native migration

Related: #1287, #1280.

- Native manual popover and CSS anchor positioning replace the transitional positioning/dismissal runtime.
- Preserve native link activation; hover/focus requests open, pointer/focus moving between trigger and card retain visibility, Escape dismisses and returns focus only when closing from within content.
- Informational previews are supplemental and noninteractive. Interactive previews expose authored region/dialog semantics, names and normal sequential focus; never autofocus on hover or trap focus. Use explicit Popover/Dialog for activation and focus transfer.
- Root owns optional contentId in React/Vue; Angular requires stable root id. Move authored Content id to Root. Vue Trigger attaches to one native child rather than a wrapper. Elements retains authored IDs or generates unique IDs.
- Retain content markup while closed for SSR relationships. Controlled owner requests remain separate from committed visibility.
- Cross-engine, placement/reflow and manual evidence remain required.
