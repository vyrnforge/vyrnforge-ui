PasswordField uses an authored show/hide action name without aria-pressed; visibility is not a pressed toggle contract. The native credential input remains mounted and the action is always type=button. Framework roots support controlled/default visibility and disabled state; cancelled actions do not request visibility changes. Angular consumers reading the old writable visible signal use isVisible() for committed state and visible/visibleChange for controlled state. Web/Elements author the native input and button, including disabled fieldset semantics. No authentication or password-manager behavior is introduced.
