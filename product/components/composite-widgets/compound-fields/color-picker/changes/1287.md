ColorPicker shares one committed six-digit lowercase hex color. The text input is an editable draft: incomplete or invalid text remains visible, complete hex input requests a normalized value, and owner updates synchronize the native picker and decorative swatch. Controlled rejection restores committed value. Native input owns color acquisition and form value; root disabled disables both inputs. Elements uses the owned native picker as the initial value and isolates nested fields. Move value/defaultValue from input parts to the root and use valid six-digit hex root values. Angular adds the swatch directive. Native picker OS UI, reset, and broader conformance evidence remain open.
