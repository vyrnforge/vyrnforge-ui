Native Web usage

Load @vyrnforge/web/styles/text.css, choose the correct semantic HTML element, then opt it into Text styling with data-vf-text and data-vf-text-variant.

<h2 data-vf-text data-vf-text-variant="heading-md">Billing and plans</h2>

API and semantics

@vyrnforge/web/text exports the shared TextVariant vocabulary and TextVariantOverrides augmentation point. The native element owns document semantics; the variant controls presentation only.

Runtime model

Text has no browser-only runtime or hydration. Existing semantic HTML remains the rendered contract. Elements applications use this same Native Web contract rather than a dedicated <vf-text> element.
