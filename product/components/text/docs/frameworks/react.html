React usage

Load @vyrnforge/web/styles/text.css and import Text from @vyrnforge/react/text.

import { Text } from '@vyrnforge/react/text';

<Text as="h2" variant="heading-md">Billing and plans</Text>

React API

as selects the native element and defaults to span; variant uses the shared TextVariant vocabulary. Supported native attributes are forwarded to the rendered element.

SSR

Server rendering preserves the requested native element and Text hooks; Text requires no browser-only activation step.
