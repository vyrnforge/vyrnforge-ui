Angular usage

Load @vyrnforge/web/styles/text.css and import standalone VfTextDirective from @vyrnforge/angular/text.

<h2 vfText variant="heading-md">Billing and plans</h2>

Angular API

vfText decorates the authored host element and variant configures the shared visual role. The directive does not replace the native host.

SSR and hydration

The authored element and Text data hooks remain present in server output; the directive does not require a separate browser runtime model.
