Vue usage

Load @vyrnforge/web/styles/text.css and import Text from @vyrnforge/vue/text.

<Text as="h2" variant="heading-md">Billing and plans</Text>

Vue API

as selects the rendered native element and defaults to span; variant uses the shared vocabulary. Normal attributes are forwarded to the native element.

SSR

Server rendering preserves the requested semantic element and Text hooks without a browser-only activation step.
