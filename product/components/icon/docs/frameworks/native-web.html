Native Web usage

Author SVG markup with the documented data-vf-icon hooks and load @vyrnforge/web/styles/icon.css or the aggregate stylesheet.

Presentation and accessibility

Use the public variant, shape, and size hooks and let the SVG inherit currentColor. Decorative icons use aria-hidden="true" and are not focusable; a meaningful standalone icon needs an authored accessible name.

Runtime model

Native Web Icon is static SVG and requires no framework runtime or hydration. Keep click, keyboard, and form behavior on the semantic control that owns the icon.
