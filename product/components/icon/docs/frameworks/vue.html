Vue adaptation

Import Icon from @vyrnforge/vue/icon, import the required artwork definition, and load the Icon stylesheet.

Props and accessibility

Pass the artwork definition and documented variant, shape, size, and optional label props. Decorative icons remain hidden from assistive technology; an owning control supplies the accessible name for icon-only actions.

Rendering

Icon renders non-interactive SVG output and can participate in Vue SSR. Do not attach activation behavior to Icon itself.
