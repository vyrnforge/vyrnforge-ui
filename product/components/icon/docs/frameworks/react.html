React adaptation

Import Icon from @vyrnforge/react/icon, import artwork such as @vyrnforge/icons/bookmark, and load the Icon stylesheet.

Props and accessibility

Pass the IconDefinition plus variant, shape, size, and optional label. Decorative icons remain hidden from assistive technology; use label only when the icon itself supplies standalone meaning.

Rendering

Icon is non-interactive and can render as SVG during React SSR. Keep activation and accessible naming on the owning control when the icon is used inside a button or link.
