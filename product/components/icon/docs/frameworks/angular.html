Angular adaptation

Import VfIconComponent from @vyrnforge/angular/icon, import the required artwork definition, and load the Icon stylesheet.

Inputs and accessibility

Bind the artwork definition and documented variant, shape, size, and optional label inputs. Decorative icons remain hidden from assistive technology; an owning control supplies the accessible name for icon-only actions.

Rendering

The component renders non-interactive SVG output and participates in Angular SSR as documented for the package. Do not attach activation behavior to Icon itself.
