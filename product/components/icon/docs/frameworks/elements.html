Custom Elements adaptation

Import defineIconElement from @vyrnforge/elements/icon, load the Icon stylesheet, and register <vf-icon> explicitly.

Properties and accessibility

Assign the rich artwork definition through the icon property and use the documented presentation attributes/properties. Keep the element decorative unless an explicit label gives the icon standalone meaning.

Upgrade model

The custom element becomes active after registration and upgrade. It remains non-interactive; activation and accessible naming belong to an owning control when composed inside an action.
