Angular adaptation

Import the standalone Dialog directives from @vyrnforge/angular/dialog and load @vyrnforge/web/styles/dialog.css or the aggregate stylesheet.

Composition and state

Apply VfDialogRootDirective to a native <dialog> and compose the title, description, body, and close directives. Bind open and handle openChange; dismissRequest exposes preventable dismissal intent and backdropDismiss opts into backdrop dismissal.

Accessibility and hydration

The authored native dialog remains the semantic element. Keep title/description IDs meaningful and let Angular application state commit requested changes during client hydration.
