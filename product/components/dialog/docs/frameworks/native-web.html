Native Web usage

Author a native <dialog> with the documented data-vf-dialog-* hooks and load @vyrnforge/web/styles/dialog.css or the aggregate stylesheet.

State and interaction ownership

Native Web intentionally adds no wrapper runtime. Application code calls showModal()/close(), owns optional backdrop and close-control policy, and restores focus when required. Escape arrives through the native cancel event.

Accessibility execution

Use the native dialog element, connect a meaningful title with aria-labelledby, add aria-describedby when useful, and preserve a visible focus path. No framework hydration is required.
