React adaptation

Import Dialog primitives from @vyrnforge/react/dialog and load @vyrnforge/web/styles/dialog.css or the aggregate stylesheet.

Composition and state

Compose DialogRoot, DialogTitle, DialogDescription, DialogBody, and DialogClose. Use open/onOpenChange for controlled state or defaultOpen where uncontrolled state is appropriate. backdropDismiss opts into backdrop dismissal.

Accessibility and hydration

Keep the authored title and optional description connected through the documented IDs. Modal activation, dismissal, and focus restoration begin in the browser; controlled React state remains authoritative through hydration.
