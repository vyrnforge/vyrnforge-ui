Vue adaptation

Import Dialog primitives from @vyrnforge/vue/dialog and load @vyrnforge/web/styles/dialog.css or the aggregate stylesheet.

Composition and state

Compose DialogRoot, DialogTitle, DialogDescription, DialogBody, and DialogClose. Bind controlled state with modelValue/update:modelValue; use the documented default-open API when uncontrolled initialization is appropriate. backdropDismiss opts into backdrop dismissal.

Accessibility and hydration

Keep the authored title and optional description connected through the documented IDs. Browser modal activation and focus behavior begin on the client while Vue state remains authoritative during hydration.
