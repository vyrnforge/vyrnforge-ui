React adaptation

Import TabsRoot, TabsList, TabsTab, and TabsPanel from @vyrnforge/react/tabs.

Selection and composition

Give each tab/panel pair the same value. Use value/onValueChange for controlled selection or defaultValue for uncontrolled initialization. Configure orientation and activation on the root.

Accessibility and hydration

Provide an accessible name on TabsList. React renders the tab roles and relationships while the VyrnForge behavior contract owns roving focus, disabled skipping, orientation/RTL movement, and manual versus automatic activation.
