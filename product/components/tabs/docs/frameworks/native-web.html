Native Web usage

Load @vyrnforge/web/styles/tabs.css or the aggregate stylesheet and author the documented Tabs hooks on native buttons and panel elements.

Behavior ownership

Native Web has no Tabs runtime wrapper. Application code must implement the documented tab roles and relationships, roving tabindex, selection/panel visibility, disabled skipping, orientation- and direction-aware arrow keys, Home/End, and activation policy. The executable example shows the automatic horizontal case.

Accessibility execution

Give the tablist an accessible name and keep each aria-controls/aria-labelledby relationship stable. Do not replace keyboard behavior with pointer-only handlers. No framework hydration is required.
