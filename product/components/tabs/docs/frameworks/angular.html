Angular adaptation

Import the standalone Tabs directives from @vyrnforge/angular/tabs and apply them to authored native elements.

Selection and composition

Compose the root, list, tab, and panel directives with matching values. Bind controlled selection through the root value input and valueChange output, or use the documented default-value input for uncontrolled initialization. Configure orientation and activation on the root.

Accessibility and hydration

Give the tablist an accessible name. The directives preserve native authored elements while applying tab roles, relationships, roving focus, disabled skipping, and the documented keyboard contract.
