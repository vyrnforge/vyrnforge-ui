Custom Elements adaptation

Import defineTabsElement from @vyrnforge/elements/tabs, load the Tabs stylesheet, and register <vf-tabs> explicitly.

Selection and composition

Mark the list, tabs, and panels with data-vf-tabs-list, data-vf-tabs-tab, and data-vf-tabs-panel; pair tabs and panels with data-vf-value. Use value for controlled selection, default-value for uncontrolled initialization, and listen for vf-value-change. orientation and activation configure keyboard behavior.

Accessibility and upgrade

On upgrade the element establishes tab roles, relationships, panel visibility, roving focus, disabled skipping, direction-aware arrows, Home/End, and manual/automatic activation. Give the authored list an accessible name.
