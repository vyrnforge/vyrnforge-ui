Native Web usage

Author a native <button> with the documented data-vf-button configuration hooks and load @vyrnforge/web/styles/button.css or the aggregate VyrnForge stylesheet.

Native API

<button
  data-vf-button
  data-vf-variant="primary"
  data-vf-size="md"
  type="button"
>
  Save changes
</button>

Native Web does not introduce a wrapper component or framework event model. Use ordinary HTML attributes, DOM events, form behavior, content, and element APIs directly.

Native state and accessibility execution

The browser supplies activation, focus, keyboard interaction, disabled behavior, and form participation. Loading is expressed through the documented VyrnForge state hook and aria-busy; accessible naming remains normal HTML/ARIA authoring.

Runtime model

Native Web requires no framework hydration. Optional Web helpers are used only where a component needs browser behavior beyond the platform's native control semantics.
