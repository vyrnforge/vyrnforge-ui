React usage

Import Button from @vyrnforge/react/button and load the canonical Web Button stylesheet or aggregate VyrnForge styles separately.

Button renders a native <button>, forwards supported native button props and the element ref, and adds the VyrnForge variant, size, and loading props. Use the native onClick callback for activation rather than a VyrnForge-specific event wrapper.

React state and accessibility execution

React owns prop/state synchronization, ref delivery, event wiring, and hydration. VyrnForge still relies on native button semantics: disabled is rendered as the native attribute, loading derives aria-busy, and an authored accessible name remains the consumer's responsibility.

Rendering and hydration

The React port renders native-complete button semantics before hydration. Hydration adds React event/ref behavior; it does not replace the semantic control or require a second VyrnForge lifecycle.
