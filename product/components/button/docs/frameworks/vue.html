Vue usage

Import Button from @vyrnforge/vue/button and load the canonical Web Button stylesheet or aggregate VyrnForge styles separately.

Component API

<script setup lang="ts">
import { Button } from '@vyrnforge/vue/button';
</script>

<template>
  <Button variant="primary" type="button">
    Save changes
  </Button>
</template>

The Vue surface is an idiomatic Vue component. It renders a native button, accepts the VyrnForge variant, size, and loading props, uses the default slot for content, and preserves appropriate fallthrough native attributes and events.

Vue state and accessibility execution

Vue owns reactive prop updates, refs, event delivery, slots, and lifecycle. VyrnForge continues to rely on the native button for activation, focus, disabled behavior, and accessible naming while the port renders shared VyrnForge state such as loading.

Rendering and hydration

The Vue port keeps the native button semantically complete before hydration. Vue hydration attaches framework behavior without replacing the underlying native control or introducing a second lifecycle layer.
