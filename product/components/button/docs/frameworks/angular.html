Angular usage

Import VfButtonDirective from @vyrnforge/angular/button and apply vfButton to a real <button>. Load the canonical Web Button stylesheet or aggregate VyrnForge styles separately.

Directive API

import { Component } from '@angular/core';
import { VfButtonDirective } from '@vyrnforge/angular/button';

@Component({
  standalone: true,
  imports: [VfButtonDirective],
  template: `
    <button vfButton variant="primary" type="button">
      Save changes
    </button>
  `
})
export class SaveAction {}

The Angular surface is intentionally a standalone attribute directive rather than a wrapper component, so the host remains the actual native <button>. Angular inputs configure VyrnForge state while native (click), button attributes, content, and form participation remain ordinary Angular/HTML behavior.

Angular state and accessibility execution

Angular owns binding updates, directive lifecycle, native event integration, and framework-safe rendering. The directive preserves the native button and renders VyrnForge-owned state such as loading without replacing native disabled, naming, focus, or keyboard semantics.

Rendering and hydration

The Angular port keeps the native control semantically complete in rendered output. Angular lifecycle and hydration integrate bindings and events without introducing a separate VyrnForge runtime model underneath Angular.
