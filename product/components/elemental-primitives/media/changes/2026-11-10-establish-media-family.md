# Establish Layer 1 Media ownership

- Group Icon and Image source ownership under `elemental-primitives/media/`.
- Keep Icon as the genuine reusable visual primitive.
- Keep Image as a native-backed `img` presentation treatment.
- Do not introduce a Media runtime component, package, or public namespace.
- Preserve all existing public package entrypoints and logical component IDs.
- Keep Skeleton and ColorSwatch outside Media pending separate review.
