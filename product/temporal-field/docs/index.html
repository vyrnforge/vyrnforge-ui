TemporalField provides a compositional wrapper around VyrnForge's native temporal input contract without inventing a custom date or time picker.

Overview

Use TemporalField when temporal input needs a stable composite boundary for adjacent field affordances.

Installation and imports

Import from each framework's /temporal-field subpath and load @vyrnforge/web/styles/temporal-field.css.

Quick start

Anatomy

Root and the existing native TemporalInput-derived input.

Variants and sizes

Temporal input types are inherited from the accepted temporal input contract.

State

Value state remains native and framework-idiomatic.

Behavior

The composite does not introduce popup calendars or custom parsing.

Interaction

Native browser temporal input interaction is preserved.

Accessibility

Consumers provide an accessible name and any validation relationships.

Forms

Name, required state, constraints, submission, and validation remain consumer-owned.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports reuse the existing temporal input foundation rather than duplicating it.

CSR and SSR

Imports are server safe.

Examples

The basic example uses a native date input.

Do / Don't

Do compose native temporal entry. Don't add a custom calendar without a separate accepted interaction contract.

Testing guidance

Test native type semantics, constraints, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
