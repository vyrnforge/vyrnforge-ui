Link preserves native anchor navigation while applying canonical VyrnForge styling.

Overview

Use Link for URL and resource navigation. The browser remains responsible for focus, activation, URL semantics, history, and modifier-key behavior.

Installation and imports

Load @vyrnforge/web/styles/link.css. React, Angular, and Vue use their /link entrypoints. Native Web uses data-vf-link on an anchor.

Quick start

Accessibility

Use a real <a> with an href for navigation and provide meaningful link text. VyrnForge does not invent a disabled-anchor state.

Styling

Canonical link styling is owned by the Web package and uses shared tokens for color, decoration, focus, and interaction states while preserving native anchor behavior.

Framework API

React and Vue expose Link; Angular decorates a[vfLink]. Native Web and Custom Elements applications use the same native anchor contract.

Compatibility

Link relies on standard anchor semantics and requires no custom navigation runtime. Application routers may compose with the framework surface as long as the resulting control remains a real anchor for navigation.

Layer boundary

Link represents one navigation action. Routing policy and application navigation workflows remain outside the library.
