NumberField composes a native numeric input with explicit increment and decrement controls while preserving consumer-owned validation.

Overview

Use NumberField when a numeric value benefits from adjacent step controls.

Installation and imports

Import from each framework's /number-field subpath and load @vyrnforge/web/styles/number-field.css.

Quick start

Anatomy

Root, numeric input, decrement, and increment controls.

Variants and sizes

No semantic variants.

State

Supports controlled and uncontrolled numeric value plus min, max, and step.

Behavior

Step controls clamp values to authored bounds.

Interaction

The input remains a native number input and step controls remain buttons.

Accessibility

Increment and decrement controls have accessible names.

Forms

Consumers retain ownership of name, required state, and validation messages.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same value and anatomy contract idiomatically.

CSR and SSR

Imports are server safe.

Examples

The basic example demonstrates bounded increment and decrement.

Do / Don't

Do use for numeric entry. Don't encode domain-specific units or calculations.

Testing guidance

Test stepping, bounds, native semantics, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
