ToggleGroup coordinates related toggle buttons as one single- or multiple-selection control.

Overview

Use ToggleGroup for a compact set of related toggle actions or choices.

Installation and imports

Import from the framework-specific /toggle-group subpath and load @vyrnforge/web/styles/toggle-group.css.

Quick start

Anatomy

Root and Item compose the public group.

State

Single mode owns one pressed value; multiple mode owns a set of pressed values, controlled or uncontrolled where supported.

Behavior

Activation updates the selected value set without introducing application state management.

Interaction

Items remain native buttons with native activation and keyboard focus.

Accessibility

The group exposes an authored accessible name and items use aria-pressed to communicate state.

Forms

Items are non-submitting buttons by default; consumers own any form serialization or validation.

Styling

Canonical CSS is Web-owned and token driven.

Framework API

Ports expose the same single/multiple selection contract idiomatically.

CSR and SSR

Imports are server safe and render deterministic pressed state.

Do / Don't

Do use for closely related toggles. Don't embed product-specific command or permissions logic.

Testing guidance

Test single and multiple modes, disabled items, pressed state, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement sibling ToggleGroup ports.
