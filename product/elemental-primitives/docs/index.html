Elemental Primitives completes the non-interactive Layer 1 inventory with native-first presentation contracts instead of redundant semantic wrappers.

Overview

The public Web contract covers Code, Kbd, Mark, Image, Skeleton, ColorSwatch, and an opt-in native prose scope. StatusIndicator and AvatarFallback remain explicitly deferred candidates. Checkmark, Radiomark, and SelectionIndicator are private recipes for later selectable controls.

Installation and imports

Load @vyrnforge/web/styles/elemental-primitives.css for this tranche or @vyrnforge/web/styles.css for the aggregate stylesheet.

Quick start

Anatomy

Each promoted primitive keeps its native element or authored container and adds only a stable styling hook. Native prose uses one data-vf-prose container around ordinary semantic HTML.

Variants and sizes

No generalized variant or size matrix is introduced. Image follows authored HTML dimensions, Skeleton follows authored layout, and ColorSwatch accepts its color through --vf-color-swatch.

State

These primitives are non-interactive. Skeleton represents presentation during loading but does not own semantic busy state. Internal selection marks never own checked or selected state.

Behavior

Code, Kbd, Mark, Image, and native prose preserve browser semantics. Skeleton motion is CSS-only and is removed under reduced motion. ColorSwatch is visual and requires equivalent text when color conveys meaning.

Interaction

Layer 1 elemental primitives add no focus, keyboard, pointer, or selection behavior.

Accessibility

Image retains ordinary native alternative-text requirements. Skeleton should be decorative with aria-hidden="true" while the owning region communicates loading state. ColorSwatch must not make color the only carrier of meaning. Native prose preserves authored semantic structure.

Forms

Elemental Primitives do not own form value, validation, submission, labeling, disabled, or read-only behavior.

Styling

Canonical CSS is low-specificity, token-driven, logical-property based, reduced-motion aware, and forced-colors compatible. Public hooks use data-vf-*. Private selection-mark classes are implementation details and are not public compatibility commitments.

Framework API

Native Web is canonical. React, Angular, Vue, and Elements consumers author the same native elements and stable hooks; no framework-specific wrapper is required for these semantics.

CSR and SSR

The contract requires no JavaScript runtime or hydration and is server-safe because semantics and styling are expressed entirely through HTML and CSS.

Examples

The executable Native Web example demonstrates all promoted primitives and representative native prose semantics.

Do / Don't

Do preserve native semantics and use Layer 1 only for elemental presentation. Don't promote deferred status/avatar semantics prematurely or expose private selection marks as public APIs.

Testing guidance

Verify native tags and attributes, stable public hooks, reduced-motion behavior, token-driven computed styles, private-recipe non-export, and zero automated accessibility violations.

Compatibility

The contract is framework-neutral and consumed through canonical Web CSS across Native Web, React, Angular, Vue, and Elements applications.
