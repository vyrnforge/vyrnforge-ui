SplitPanel composes two content panes with an accessible resize separator without owning application layout state.

Overview

Use SplitPanel when adjacent regions need an adjustable boundary.

Installation and imports

Import from each framework's /split-panel subpath and load @vyrnforge/web/styles/split-panel.css.

Quick start

Anatomy

Root, two panes, and a resize handle.

Variants and sizes

Minimum, maximum, and initial percentage are explicit inputs.

State

Supports controlled and uncontrolled split percentage.

Behavior

The separator clamps resizing to authored bounds.

Interaction

Arrow keys adjust the split; Home and End move to bounds where supported.

Accessibility

The resize handle uses separator semantics with value bounds and current value.

Forms

Not form-associated.

Styling

Canonical CSS is Web-owned and driven by a shared split-size custom property.

Framework API

Ports expose the same panes and resize contract idiomatically.

CSR and SSR

Imports are server safe.

Examples

The basic example begins at a 50 percent split.

Do / Don't

Do use for adjustable adjacent regions. Don't turn it into application shell state or persistence.

Testing guidance

Test keyboard resize, bounds, ARIA values, SSR, and axe.

Compatibility

React, Angular, Vue, and Elements implement the shared concept.
