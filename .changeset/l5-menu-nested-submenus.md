Compose native nested submenus with existing Menu parts. Nested triggers participate in parent menu navigation, logical inline-end opens, inline-start/Escape dismisses one level, and command activation/Tab close the chain. Default bottom-start placement becomes logical inline-end for nested surfaces. Existing authored labels and controls IDs remain supported.
