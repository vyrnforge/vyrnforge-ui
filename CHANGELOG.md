# Changelog

VyrnForge release notes are assembled from scoped unreleased change fragments owned by components, packages, and reusable product units. Contributors do not edit this file for every pull request.

Public release fragments use `major`, `minor`, or `patch`. Repository-only refactors use `internal`. Release tooling validates fragments and can render the current unreleased view with `npm run changes:preview`.

Released versions will be appended here by the release process when VyrnForge leaves rebuild bootstrap status.
